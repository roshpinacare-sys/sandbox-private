# portal — גשר-הפורטל (מראה-של-הפרויקט-הראשי)

עותקי-קבצים-מהפרויקט-הראשי (Next.js) שמחברים-את-דף-הבית-אל-שרת-HQ:
- `page.tsx` — שער-הכניסה + הדשבורד (עברית, RTL, ערוץ-זהות-כפול)
- `hq-session.ts` — עזרי-זהות (cookie + כותרת x-hq-session)
- `ensure-hq.ts` — הבטחת-חיים-ל-HQ
- `api/sandbox/{login,logout,status,action}/route.ts` — הפרוקסי

המקור-החי-רץ-בפרויקט-הראשי; כאן-הגיבוי-הריבוני-בגיט.
תיקון-Task-42.1: ערוץ-זהות-כפול (תצוגת-iframe), IP-אמיתי-לנעילת-ניסיונות, טוקן-גם-בגוף-התשובה.

## שחזור-מגיט-אוטומטי + כרטיס-ריבונות-כוללני (Task 44-c)

- `ensure-hq.ts` — מעבר-להקמה-מחדש: אם-פורט-3010-מת **וגם** `sanbox/server.ts` לא-קיים,
  משחזר-קודם-את-התיקייה-מהריפו-הפרטי (`git clone`; תיקייה-קיימת-שאינה-ריקה →
  init+fetch+checkout כופה — משחזר-רק-נעקבים, לא-נוגע-ב-secrets/).
  PAT מ-`~/.sovereign/remote.env` (או `sanbox/secrets/pat.env` אם-שרדה); אין-PAT → שקט,
  השומר-העצמאי-יטפל. הטוקן-רק-דרך-GIT_ASKPASS-זמני-תחת-tmpdir (מצב 700) + `HQ_TOKEN`
  בסביבת-התהליך — לא-ב-argv, לא-ב-URL, לא-ב-.git/config; ה-helper-נמחק-תמיד.
  Debounce-שחזור-נפרד (120 שניות) מלבד-debounce-ההקמה (30 שניות).
- `page.tsx` — כרטיס-'ריבונות' כוללני: שומר-ריבונות-עצמאי (guardian), גיבוי-כספת-מוצפן
  (ts/hash/KB או 'אין גיבוי'), סנכרון-ריפו (ahead/behind, 0/0 = מסונכרן), כפתור-'גבה עכשיו'
  ומקטע-'שחזור-כספת' (שדה-סיסמה שנשלח-פעם-אחת-בגוף-הבקשה-ונמחק-מהמצב-מיד —
  אינו-נשמר-בשום-מקום). הנתונים-מגיעים-מ-`ops.{guardian,vaultBackup,repoSync}`-בסטטוס.
- `api/sandbox/action/route.ts` — פעולות-חדשות: `vault-backup` (ללא-פרמטרים)
  ו-`vault-restore` (מעביר-גם-`password`-מהגוף; הסיסמה-לא-נכנסת-ללוגים/קבלות/תשובות).
